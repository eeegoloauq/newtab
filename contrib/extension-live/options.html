The colour is what the tab shows for the moment before your page appears. It is read from the page once, after you allow it — nothing to look up. Refuse, and you can still type it: your page prints it at /manifest.webmanifest as background_color.

Running newtab on this machine? That is the address above. Running it on a server? Use its address instead. Saved as you type — there is no other button.

With an address set, a new tab goes straight there, so this page is reached from the toolbar button or chrome://extensions. Empty it to get the reminder back.
