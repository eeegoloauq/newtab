
## Install

| File | For |
|---|---|
| `newtab-linux-amd64`, `newtab-linux-arm64` | The server, one binary per CPU |
| `newtab-extension-offline.zip` | A new tab extension with the example links |
| `newtab-extension-live.zip` | A new tab extension that opens your running server |
| `ghcr.io/eeegoloauq/newtab` | The Docker image, see `contrib/compose.yaml` |

`SHA256SUMS` lists the checksum of every file.
